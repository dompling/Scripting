# RefreshSideStore

**SideStore 签名倒计时 / 桌面小组件（Scripting）**

通过 Scripting 在 iPhone 桌面展示 SideStore 及其他已安装自签应用的签名剩余天数。支持小号、中号两种布局，流色/深色背景设置，并支持快捷指令全自动化刷新与桌面静默交互。

## 功能

- **真实到期时间（推荐）**：使用设备的 RPP 配对记录建立 RemotePairing / RSD 连接，通过 `misagent CopyAll` 只读查询描述文件，再结合 `installation_proxy` 当前已安装应用列表过滤，排除已经卸载的应用残留记录。
- **一键静默刷新**：右上角精心内置点击手势按钮（`Button shortcutIndex`），在桌面轻触小手指即可在后台静默运行快捷指令同步数据，并伴随物理触觉反馈，不弹任何 App。
- **动态跟随进度渐变**：支持底部背景渐变色随马蹄圈指针位置颜色（绿 -> 黄 -> 橙 -> 红）动态演变，直观呈现证书健康状态。
- **隧道连接**：支持设备配对（自动填入验证码）、导入配对记录、指定反射 IP 和 RemotePairing 端口；默认反射 IP `10.7.0.1`，端口可自动探测与回退。
- **桌面展示**：小号马蹄圈；中号支持最多三个应用的名称、剩余天数与进度条；可调整应用排序。
- **外观**：支持浅色/暗色和独立底部渐变颜色选择，暗黑底色默认对齐 iOS 标准 `#1C1C1E`，明亮底色默认 `#FFFFFF`。

## 搭配快捷指令使用（全能单指令）

现已升级为**单条整合型全能快捷指令**，一条指令原生同时支持**手动点击运行**与**充电智能自动化**：

1. **手动运行**：立即执行 SideStore 续签 -> 自动触发 Scripting 极速扫描证书 -> 静默同步小组件数据。
2. **智能自动化**：指令内部**自带时间判定逻辑**（检测距离上次刷新是否超过 5 天），只需配合「连接电源（充电时）」触发即可，未满 5 天绝不无谓打扰，到期自动静默续签并更新小组件！
3. **桌面小组件点击静默运行**：完美支持在小组件右上角手指处直接触发。

### 使用方法

#### 1. 配置桌面小组件（右上角手指静默刷新）
1. 在桌面长按 **RefreshSideStore** 小组件，选择 **「编辑小组件」**；
2. 在 **「快捷操作 / Shortcuts」** 列表中添加上述快捷指令作为第 1 项（Index 0）；
3. **「点击后」** 设置为 **`什么都不做`**；
4. 现在，在桌面上轻点小组件右上角的 **手指图标**，即可在后台静默执行快捷指令并伴随触觉微震刷新小组件，完全不跳 App！

#### 2. 配置充电自动化（智能识别超时）
1. 打开 iOS **「快捷指令」->「自动化」**，新建个人自动化；
2. 触发条件选择：**「连接充电器」**（当 iPhone 接通电源时）；
3. 执行动作：选择运行上述 **`RefreshSideStore` 快捷指令**；
4. 关闭“运行前询问”。
   > **智能机制**：快捷指令内部会自动检测本地证书时间，**只有距上次刷新超过 5 天且处于充电状态时**才会真正执行续签与扫描，完全不需要手动去算天数或定时！

#### 3. 备选方案：通过小组件传参启动扫描
如果你不想配置快捷操作列表，也可以使用系统传参直接唤起扫描：
1. 在桌面长按小组件选择 **「编辑小组件」**；
2. 将 **「点击后」** 设为 **`运行脚本（单实例）`**；
3. 将 **「参数」** 填入 **`scan`**（或 **`扫描自签`**）；
4. 保存后点击小组件，脚本将以轻触微震启动极速扫描，并在 Wi-Fi 可用时更新数据、发送单行结果通知后秒级退出。

## 扫描自签与 Wi-Fi 提示

在进行自签扫描时，必须处于 Wi-Fi 局域网隧道环境。若检测到未连接 Wi-Fi，系统会自动弹出温和的通知提示：`运行参数「扫描自签」仅在 Wi-Fi 局域网隧道下生效，请连接 Wi-Fi 后重试`，避免死板抛出网络超时报错。

## 说明与隐私

- 配对记录包含设备敏感凭据，**仅在本机保存**，不要提交 `.mobiledevicepairing`、`.plist` 配对文件或任何私钥。
- RPP 查询仅用于读取应用安装信息和签名描述文件，**不执行安装、卸载或续签**。
- `src/` 包含从组件包导出的源代码，方便审核、修改与提交 Issue。
